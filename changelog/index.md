# Changelog

## Version 1.0.0

- **[Initial release]** Flutter viewer app for Android and iOS: guest mode, vertical player with adaptive streaming, unlocks with coins, one ad, Series Pass or VIP, wallet, coin store, rewards, library, search, creator profiles and notifications
- **[Initial release]** Admin Panel: titles, categories, uploads, release schedule, Home builder, creators and review queue, users, support tickets, push, monetization per region, transactions, settings, team and roles, audit log
- **[Initial release]** Creator Portal for approved creators, with review of every episode
- **[Initial release]** Public website, edited from the Admin Panel, in several languages
- **[Initial release]** Video on this server with ffmpeg, on Amazon S3, or on Cloudflare Stream
- **[Initial release]** Web installer, licence activation and update packages

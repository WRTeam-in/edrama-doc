The environment file (.env)

The .env file in the project folder holds the settings that change only when you deploy: the database connection, the app's address, and a few switches. Almost everything else (branding, keys for Firebase or the stores, prices, features) is set in the Admin Panel instead, so you rarely need to touch this file.

warning

.env contains your database password and APP_KEY, the key that signs every session and encrypts stored secrets. Never share it, never let it be reachable from the web, and keep a copy of APP_KEY with your backups: if it is lost, saved keys in Settings can't be read back.

After editing .env, apply the change:

Server
php artisan config:cache
php artisan queue:restart

Some settings are already in .env with a # in front: remove the # to use one. A setting that isn't in the file at all can be added on its own line, as NAME=value.

Set by the installer​

SettingMeaning
APP_URLYour site's address, such as https://admin.your-domain.com.
APP_ENVproduction on a live server. The System page warns you if it isn't.
APP_DEBUGfalse on a live server, so error pages never show internals.
DB_*The database connection.
EDRAMA_INSTALLERfalse once installed. The installer only opens while this is true and no install marker exists.
EDRAMA_LICENSE_ENFORCEDtrue once installed: the purchase code is checked (see License & updates).
SESSION_DRIVER, CACHE_STORE, QUEUE_CONNECTIONAll database: sessions, cache and the job queue live in MySQL, so no Redis is needed.
APP_KEYGenerated once. It signs sessions and encrypts the keys you save in Settings.

If you move to another domain, change APP_URL too: the purchase code is registered to its domain (License & updates).

Advanced: video encoding, rate limits and housekeeping

You rarely need these. Change one only when a page or WRTeam support tells you to.

SettingDefaultWhat it does
EDRAMA_VIDEO_MAX_DURATION_SECONDS900The longest episode accepted, in seconds (15 minutes).
EDRAMA_TRANSCODE_TIMEOUT540How long one ffmpeg run may take, in seconds. Raising it also needs the slow workers' --timeout and DB_QUEUE_RETRY_AFTER raised.
EDRAMA_TRANSCODE_PRESETveryfastThe x264 preset: faster presets use less CPU, slower ones make smaller files.
EDRAMA_TRANSCODE_THREADS2Encoder threads per ffmpeg run. 0 lets ffmpeg decide; keep it low on shared hosting ("Error while opening encoder").
EDRAMA_UPLOAD_CHUNK_MB8The size of the pieces browsers upload videos in. Must stay below your web server's body limit.
EDRAMA_KEEP_VIDEO_SOURCEtrueKeeps the uploaded original, for re-encoding and storage moves.
EDRAMA_SUBTITLE_DISKfilesThe storage subtitle files live on.
EDRAMA_API_ANONYMOUS_IP_PER_MINUTE1200Requests per minute from one IP address before sign-in (many phones can share one carrier address).
EDRAMA_API_SESSION_IP_PER_MINUTE300Requests per minute per IP address for signed-in sessions.
EDRAMA_MEDIA_PER_MINUTE3000Requests per minute per IP address to signed media links (video playlists and segments).
EDRAMA_TABLE_EXPORT_MAX_ROWS50000The most rows one table download holds. Filter for more.
EDRAMA_IMPORT_MAX_ROWS1000The most rows one bulk-import file holds.
EDRAMA_FAILED_JOB_DAYS30Failed jobs older than this are deleted daily.
EDRAMA_WEBHOOK_EVENT_DAYS90Processed store and video notifications older than this are deleted daily (at least 7).
EDRAMA_AD_LIMIT_MODEper_ad_unitThe starting value for whether unlock ads and Rewards ads share one daily limit (shared). Change it per region in Monetization › Ads instead.
EDRAMA_IDEMPOTENCY_TTL_HOURS, EDRAMA_IDEMPOTENCY_LOCK_SECONDS24, 60How long a purchase or unlock request is remembered, so a retried request never charges twice.

Leave these alone​

SettingWhy
EDRAMA_DEMO_MODE, EDRAMA_DEMO_*Only for WRTeam's public demo server: makes both panels read-only. Keep them off.
EDRAMA_FAKE_FIREBASE_TOKENSDeveloper testing only. Never true in production.
APP_KEYChanging it makes saved secrets unreadable. If you must replace it, put the old key in APP_PREVIOUS_KEYS.
APP_DEBUGtrue shows error details, including secrets, to everyone. Keep it false.
EDRAMA_LICENSE_VALIDATOR_URL, EDRAMA_LICENSE_ITEM_IDWhere and how your purchase code is checked. Changing them stops the license check working.
EDRAMA_APP_LANGUAGES, EDRAMA_VIDEO_PROVIDERStarting values the installer uses. Change languages and the video provider in Settings instead.

Server installation

The server software (the Admin Panel, the Creator Portal and the API) is installed once, on a server you control. The package already contains everything it needs to run: you do not need to install Composer or Node.js on the server, and you never run a build step.

What you'll need​

A serverA VPS (recommended) or shared hosting with PHP 8.5, MySQL 8 and the ability to run ffmpeg.→A domain with HTTPSSuch as admin.your-domain.com, pointed at the server, with an SSL certificate.→Your purchase codeFrom your CodeCanyon downloads page. It is registered to your domain.→An empty MySQL databaseA database name, a user that can create and change tables, and its password.→

Server requirements​

The web installer checks all of these and marks anything missing in red.

RequirementDetails
PHP8.5.0 or newer
PHP extensionsbcmath, ctype, curl, fileinfo, gd, intl, json, mbstring, openssl, pdo_mysql, sodium, tokenizer, xml, zip
PHP functionproc_open must be allowed (not in disable_functions): the cron line starts each task through it, and ffmpeg runs through it
RecommendedThe pcntl extension, so a background job that hangs is stopped at its time limit
DatabaseMySQL 8 (an empty database)
Writable by the web serverstorage, storage/app, storage/framework/cache, storage/framework/sessions, storage/framework/views, storage/logs, bootstrap/cache, and the .env file
Video processingffmpeg and ffprobe, unless you use Cloudflare Stream (details)
Background workOne cron entry every minute; supervisor is recommended on a VPS (details)
Web serverApache or nginx, with the domain pointing at the package's public folder
Upload sizeAt least 16 MB for upload_max_filesize and post_max_size (videos upload in 8 MB pieces), and the same for the web server's body limit (nginx client_max_body_size is only 1 MB by default). Higher if you'll install update packages or import AI Studio clips from the browser (up to 300 MB).
Outgoing HTTPSThe server must reach WRTeam's license server (to check your purchase code), Firebase, the stores and your video service.
HTTPSAn SSL certificate on your domain: the app and the website only talk to https:// servers.
Which server?

A small VPS (2 CPU cores, 4 GB of memory) handles a launch comfortably. Video processing is the heaviest job: every upload is turned into four qualities on your server. If your hosting is small, choose Cloudflare Stream in Admin Panel›Settings›Storage & video and your server does no video work at all.

Video: choose who does the work​

Every uploaded episode is turned into adaptive streaming video in four qualities (1080p, 720p, 480p and 360p). You choose who does that in Admin Panel›Settings›Storage & video, and can switch later.

OptionYou needGood for
This server (the default)ffmpeg on the serverGetting started and small catalogues
Amazon S3 (or S3-compatible)ffmpeg on the server, plus a bucketGrowing catalogues: storage grows without filling your disk
Cloudflare StreamA Cloudflare account with Stream. No ffmpeg.No video work on your server. Cloudflare bills for minutes stored and watched.

The largest episode file is 20 GB by default (up to 200 GB, set in Admin Panel›Settings›Video pipeline), and the longest episode is 15 minutes.

A typical domain layout​

AddressWhat runs there
admin.your-domain.comThis package: the Admin Panel (/admin), the Creator Portal (/creator), the API (/api/v1), share pages (/s/…, /c/…) and legal pages (/legal/…)
your-domain.com or www.your-domain.comThe public website, hosted separately

The installation, step by step​

  1. Prepare the server. Install PHP, MySQL and ffmpeg, upload the package and point your domain at its public folder. Follow VPS server or Shared hosting.
  2. Run the web installer. Open your domain in a browser and complete four screens: requirements, purchase code, database and Owner account. See Web installer.
  3. Start the background work. Add the cron line, and on a VPS the queue workers. See Cron & queues.
  4. Check video processing. Make sure ffmpeg is found, or choose Cloudflare Stream. See Video processing.
  5. Finish the setup. Sign in, connect email and Firebase, set your branding and remove the demo data. See After installation.

What's in the download​

Your CodeCanyon download holds one zip per part, each named with its version:

ZipWhat it isGuide
edrama-backend-<version>.zipThe server: Admin Panel, Creator Portal, API and installerThis section
edrama-app-<version>.zipThe Flutter app for Android and iOSMobile app setup
edrama-website-<version>.zipThe public website (Next.js)Website

Inside the backend zip:

Folder or fileWhat it is
app, bootstrap, config, database, lang, resources, routesThe application.
vendorEvery PHP library it uses, already included.
publicThe only folder the internet should see. Your domain points here.
public/buildThe panels' styles and scripts, already built.
storageLogs, sessions, uploads (when files stay on this server).
.envThe settings file. The installer fills it in. Some computers hide files whose names start with a dot: make sure it is uploaded.
.htaccessUsed only when your domain can't point at public (see Shared hosting).
docs/deploy/A ready-made supervisor.conf (Cron & queues) and ffmpeg-shared-hosting.md (Video processing).
artisanThe command-line tool for the server commands.

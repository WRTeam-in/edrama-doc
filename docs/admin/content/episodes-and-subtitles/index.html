Episodes and subtitles

Open a title and choose the Episodes tab to manage its episodes, or Localization for subtitles.

The columns​

ColumnMeaning
EpisodeIts number and name ("Untitled" until named).
LengthThe video's length, once processed.
AccessFree (within the free episodes) or Locked.
StatusDraft, In review, Approved, Live and so on.
ProcessingUploading, Processing, Ready or Failed (with the reason).
SubtitlesWhich languages have subtitles.
ReleaseReleased on a date, scheduled for a date, or not scheduled yet.

Actions on an episode​

ActionWhat it does
Play episodePlays it right in the panel, whether it's on this server, Cloudflare Stream or YouTube. If a replacement video is processing, you see the current one until the new one is ready.
Comments and likesOpens what viewers said about this episode.
RenameClick the name to change it.
ScheduleSets the publish time (Release schedule).
Delete episodeOnly an unreleased episode that no viewer has paid for. The episode and its video go for good.
Allow short episodeSee below.

The 45-second floor​

eDrama won't release a paid episode shorter than 45 seconds (the "length floor", set in Admin Panel›Settings›Video pipeline). Viewers complain when late episodes are cut into seconds-long pieces to sell more unlocks, so a coin should always buy a real scene.

If an episode is shorter for a good reason, such as the finale's epilogue, use the warning button on its row: Allow short episode, give the reason, and choose Allow it. The reason goes in the audit log. Creators can't submit episodes under the floor at all.

Replacing a video​

Upload a new file with the same episode number. Viewers keep watching the current video until the new one is processed, then switch over. If the new upload fails, the old one stays.

Subtitles​

Open the Localization tab. Each episode has a row and each app language a column, with how many episodes are covered.

  1. Choose Upload in the cell for the episode and language.
  2. Choose a WebVTT (.vtt) or SubRip (.srt) file: UTF-8 text, up to 1 MB.
  3. Choose Upload.

The file is checked: times must run in order and end within the episode's length (plus one second). SRT files are converted to WebVTT automatically; the message says how many subtitle lines were found. A new file for the same episode and language replaces the old one.

If the episode's video isn't processed yet, the file is checked against its length once it is.

In the app, viewers choose subtitles in the player's menu or in App›Me›Settings›Subtitles ("Same as app language" by default).

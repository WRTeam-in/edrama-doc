<Path>System › License & updates</Path> shows your license and installed version, and is where the **Owner** activates the license and installs updates.

| Card | What it shows |
|---|---|
| **License** | Active or not active, the purchase code (masked), the domain it's registered to, the buyer, when it was last checked, and whether the check is enforced on this install. |
| **Version** | The installed version, the last update, and the update history (from → to, applied or failed). |
| **Activate your license / Install an update** | One form for both: the purchase code, an optional update package (.zip), and the backup confirmation. |

Only the Owner can submit the form. The full steps, what's checked and why an update can be refused are in [License & updates](../../installation/license-and-updates.mdx).

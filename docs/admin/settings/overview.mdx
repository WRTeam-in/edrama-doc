## The sections

| Group | Section | What it holds |
|---|---|---|
| **Brand & look** | [Branding](branding.mdx) | App name, tagline, logos, favicon, wordmark font, theme colour, the Studio's default theme |
| | [Sign-in screen](branding.mdx#sign-in-screen) | The photos, motion, poster strip and words of the sign-in pages |
| **App & content** | [Regions & languages](regions-and-languages.mdx) | App languages and their files, the Studio language, the reporting currency and exchange rates |
| | [App & support](app-and-support.mdx) | App versions and store links, support email, feature switches, maintenance mode, comment blocklist |
| | [Video pipeline](storage-and-video.mdx#video-pipeline) | Upload size, YouTube episodes, creator upload limits, release delay |
| | [Storage & video](storage-and-video.mdx) | Where files live (this server, Amazon S3, Cloudflare R2) and what streams videos (this server or Cloudflare Stream) |
| | [AI Studio](ai-studio.mdx) | Switch, models, limits, prices, keys and billing |
| **Money** | [Payments](payments-and-revenue.mdx) | Revenue share, store fees, creator price limits, spend cap choices, adjustment approval limit, Google Play and App Store keys |

## Integration keys

Keys for outside services sit on **cards** at the end of their section. Every card has a **Where do I find these?** guide with the exact steps and links, the webhook or redirect address to copy, **Save** and **Test connection**.

| Card | Section |
|---|---|
| Google Play, App Store | Payments |
| AdMob Reporting API | Creator revenue |
| Amazon S3 bucket, Cloudflare R2 bucket, Cloudflare Stream | Storage & video |
| Firebase, System alerts | Notifications |
| SMTP server | Email delivery (SMTP) |

:::info[Secrets are write-only]
Keys are **stored encrypted** and **never shown again** after saving: the field reads "Saved. Leave empty to keep it." Type a new value only to replace it. A value that came from the server's `.env` file says so; saving one here replaces it. Save before **Test connection**: it checks the keys as saved.
:::

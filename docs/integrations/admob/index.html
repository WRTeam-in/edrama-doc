AdMob

eDrama uses AdMob rewarded ads in two places: to unlock an episode, and to earn bonus coins on the Rewards tab. AdMob is set up in three places:

WhereWhat
The app projectThe AdMob app IDs (Ads setup).
Admin Panel›Money›Monetization›AdsThe ad unit IDs per platform and region, and the limits.
Admin Panel›Settings›Creator revenueThe AdMob Reporting API, so unlock-ad earnings can be shared with creators.

1. Create the ad units​

In AdMob, for each app (Android and iOS), create two Rewarded ad units: one for unlocks, one for Rewards. Each ID looks like ca-app-pub-0000000000000000/0000000000.

2. Turn on server-side verification​

For every ad unit: AdMob › Ad units › the unit › Server-side verification › enter the callback URL shown on the Ads tab in Monetization.

Required

An ad unlocks an episode or pays coins only once AdMob confirms it through this callback. Without server-side verification, ads play but reward nothing.

3. Enter the units​

In Admin Panel›Money›Monetization›Ads, for each region: Unlock ad unit ID (Android / iOS) and Rewards ad unit ID (Android / iOS), plus the daily limits and coins per Rewards ad. A platform without a unit shows no ads in that region.

4. Connect the Reporting API (for creator revenue)​

So the monthly import can read your unlock ads' earnings by country and ad unit (read-only):

  1. In Google Cloud, enable the AdMob API. Set up APIs & Services › OAuth consent screen and publish it (in testing mode, Google ends the connection after 7 days).
  2. Credentials › Create credentials › OAuth client ID › Web application. Add the Authorised redirect URI shown on the AdMob Reporting API card.
  3. Paste the OAuth client ID and client secret on the card and Save.
  4. Choose Connect AdMob and sign in with the Google account that owns the AdMob account. The refresh token and publisher ID (pub-…) are filled in.

Without it, creator revenue's ads pools stay at zero unless set by hand.

Rules eDrama enforces​

One ad, one reward; 30 seconds at most; no playable or interactive ads in the unlock path; never shown to VIP; never auto-played. Use AdMob's Blocking controls to keep interactive formats out of your rewarded units.

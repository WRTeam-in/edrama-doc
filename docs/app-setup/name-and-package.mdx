Your app needs its own name and its own **package name** (on iOS, **bundle ID**): a unique identifier such as `com.yourcompany.drama` that the stores use to tell your app apart from every other app. Choose it carefully: **it can't change once the app is published.**

<CommonGuide to="GeneralSettings/packagename" title="Package name" text="Why the package name matters, how to pick one, and changing it in a Flutter project." />

## The app's name

There are three places, because the platforms read the name under the icon before the app starts:

| Where | File | Setting |
|---|---|---|
| Inside the app (splash, Home header, share text) until the server sends its own | `lib/app/config/app_config.dart` | `appName` |
| Under the icon on Android | `android/app/src/main/AndroidManifest.xml` | `android:label="eDrama"` |
| Under the icon on iOS | `ios/Runner/Info.plist` | `CFBundleDisplayName` (or **Display Name** in Xcode › Runner › General) |
| iOS permission prompts (photo library, camera, ad tracking) | `ios/Runner/Info.plist` | `NSPhotoLibraryUsageDescription`, `NSCameraUsageDescription` and `NSUserTrackingUsageDescription`: each sentence names "eDrama", so change it to your app's name |

```dart title="lib/app/config/app_config.dart"
static const String appName = 'eDrama';
static const String companyName = 'WRTeam';
```

`companyName` is read out for the company logo at the bottom of the splash screen.

:::tip
Inside the app, the name from <Path>Settings › Branding › App name</Path> wins once the server answers, so keep both the same.
:::

## The package name

<Tabs>
<TabItem value="android" label="Android">

<Steps>

1. Open `android/app/build.gradle.kts` and change **both** `namespace` and `applicationId`:

   ```kotlin title="android/app/build.gradle.kts"
   namespace = "com.yourcompany.drama"
   // …
   applicationId = "com.yourcompany.drama"
   ```

2. Move `MainActivity.kt` to match: in the download it lives in `android/app/src/main/kotlin/com/example/edrama/`. Create the folders `com/yourcompany/drama/`, move the file there, delete the old folders, and change its first line to `package com.yourcompany.drama`.

</Steps>

</TabItem>
<TabItem value="ios" label="iOS">

<Steps>

1. Open `ios/Runner.xcworkspace` in Xcode.
2. Select **Runner** › **Signing & Capabilities** and change **Bundle Identifier** (this sets `PRODUCT_BUNDLE_IDENTIFIER`) for every build configuration.
3. Choose your Apple **Team** for signing. The download has none, so iOS builds fail until you pick one.
4. The **RunnerTests** target uses `com.example.edrama.RunnerTests`: change it to match, such as `com.yourcompany.drama.RunnerTests`.

With automatic signing, Xcode registers the capabilities the app already uses for your new App ID: Push Notifications, Sign in with Apple, Associated Domains and App Attest.

</Steps>

</TabItem>
</Tabs>

Then update the same value in `app_config.dart`. YouTube's embedded player requires it as the referrer:

```dart title="lib/app/config/app_config.dart"
static const String appId = 'com.yourcompany.drama';
```

:::tip[Or rename it automatically]
The `change_app_package_name` tool renames the Android and iOS IDs and moves the Kotlin folder in one go:

```bash title="Terminal, in the app folder"
dart pub add --dev change_app_package_name
dart run change_app_package_name:main com.yourcompany.drama
```

Check the places above afterwards, and set `appId` in `app_config.dart` yourself: the tool doesn't touch it.
:::

## Afterwards

Everything else that uses the package name:

| Where | What to set |
|---|---|
| **Firebase** | Add apps with the **new** IDs and run `flutterfire configure` again ([Firebase](firebase.mdx)). Do this step first, Firebase second. |
| **Admin Panel** | In <Path>Settings › Payments</Path>: **Package name** on the Google Play card, and **Bundle ID** on the App Store card ([Google Play](../integrations/google-play.mdx), [App Store](../integrations/app-store.mdx)). |
| **Server `.env`** | `EDRAMA_ANDROID_PACKAGE` (your application ID) and `EDRAMA_IOS_APP_ID` (your Apple Team ID, a dot, then your bundle ID, such as `ABCDE12345.com.yourcompany.drama`) ([Deep links](deep-links.mdx)). |

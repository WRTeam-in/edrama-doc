What to include​

The faster we understand the problem, the faster we can fix it:

  • Your purchase code (where to find it)
  • Your domain
  • What you did, what you expected, and what happened
  • Screenshots of the screen and any error
  • For server problems: your PHP version (php -v), the last lines of storage/logs/laravel.log, and a screenshot of Admin Panel›System›System showing the queues and scheduled tasks
  • For app problems: the app version (bottom of the Me tab), the phone model and OS version
  • For app build problems: the output of flutter --version and the full build error
Never send passwords or keys by email

We'll never ask for your database password, APP_KEY or service-account files. If we need access to your server, we'll agree a secure way first.

What support covers​

  • Installation and configuration help
  • Bugs in eDrama, and their fixes
  • Guidance on features and settings
  • Help with updates

Setting up your own computer for Flutter (Android Studio, Xcode), your hosting account, store developer accounts, and custom changes to the code aren't included. Ask us about a quote for those.

Installation service​

Prefer to hand it over? WRTeam can install the server, set up cron, queues and ffmpeg, connect Firebase, the stores and AdMob, and build and publish your branded app. Email us with your purchase code.

Rate eDrama​

If eDrama works well for you, a rating on your CodeCanyon downloads page helps us keep improving it. Thank you!

Troubleshooting

Find the symptom, check the likely cause, apply the fix. Most problems show up first on Admin Panel›System›System: start there.

Server and installation​

SymptomLikely causeFix
The installer shows Folder permissionsThe web server can't write storage, bootstrap/cache or .env.Folders 755/775, files 644/664, owned by the site's user. Upload the hidden .env if missing.
Connected, but the tables could not be createdThe database user can't create tables.Give it All privileges on the database; press Continue again.
A 500 error page after installingWrong permissions, or a missing PHP extension.Check storage/logs/laravel.log; the System page names permission problems.
/.env opens in the browserThe domain points at the project folder.Point it at public, or upload the package's .htaccess. Then change the DB password and APP_KEY.
This server isn't set up as a live serverAPP_ENV/APP_DEBUG are development values.APP_ENV=production, APP_DEBUG=false, then php artisan config:cache.
Everyone shares one IP (lockouts hit everybody)A proxy/CDN isn't trusted.EDRAMA_TRUSTED_PROXIES=cloudflare (or *), then config:cache.
Both panels redirect to /activateThe purchase code was refused (invalid or another domain).Owner enters the code again; contact WRTeam if it's refused.

Background work​

SymptomLikely causeFix
Cron not running on SystemNo cron line, or the wrong PHP/folder.Copy the line from System › Server setup; wait 2 minutes.
Tasks marked lateThe cron stopped.Same as above; check the hosting panel didn't disable it.
Jobs pile up under Jobs waitingNo queue worker.Shared hosting: keep EDRAMA_QUEUE_WORKER_SCHEDULED=true. VPS: start supervisor.
Failed jobsA job hit an error (shown in its first line).Fix the cause, then Retry.
Changes to .env have no effectConfig is cached; workers run old code.php artisan config:cache and php artisan queue:restart.

Video​

SymptomLikely causeFix
ffmpeg not foundNot installed, or not on the path.Install it, or set EDRAMA_FFMPEG_PATH/EDRAMA_FFPROBE_PATH.
Stuck on ProcessingNo queue worker.See Background work.
Processing, then FailedThe host killed the long job (memory/CPU limits).Use Cloudflare Stream or a bigger server.
Upload stops at a percentageConnection dropped.Choose Retry: it resumes.
Upload refused immediatelyOver the size limit, or not MP4/MOV/MKV.Check Admin Panel›Settings›Video pipeline.
Episodes upload but nginx returns 413Request body limit.client_max_body_size ≥ 16M (8 MB chunks).
Video won't play in the appNot processed, not released, or the viewer hasn't unlocked it.Play it from the title's Episodes tab; check its status and release.

Money​

SymptomLikely causeFix
Purchases fail verificationStore keys missing or wrong, or the product IDs don't match.Check the Google Play / App Store cards and press Test connection. Check the IDs in Monetization match the store products. (The App Store card's Environment doesn't affect purchases: they're checked with production, then the sandbox.)
Refunds made in the store don't showNotifications not set up.Set up Google's Pub/Sub push and Apple's Server Notifications.
Ads play but don't rewardNo server-side verification.Set the callback URL on each AdMob unit.
No ads at all on one platformNo ad unit for that platform in the region.Fill in the unit IDs in Monetization › Ads.
Revenue left out of totalsMissing exchange rate.Add it in Settings › Regions & languages.
Creator revenue ads pools are zeroAdMob Reporting API not connected.Connect AdMob in Settings › Creator revenue, or set pools by hand.

Notifications and email​

SymptomLikely causeFix
Pushes aren't set up yetNo Firebase keys.Settings › Notifications › Firebase.
Test push: No app account … has a device that takes pushesYour app account doesn't use the same email, or notifications are off.Sign in to the app with your Studio email; allow notifications.
iOS gets no pushesNo APNs key in Firebase.Upload the APNs key in Firebase › Cloud Messaging.
Pushes arrive lateQuiet hours or the daily cap.Expected; adjust in Settings › Notifications.
No emails at allMailer writes to the log.Add an SMTP server; Send test email.
Emails in spamMissing SPF/DKIM/DMARC.Add them for your sending domain.

The app​

SymptomLikely causeFix
No internet connection on every screenWrong apiBaseUrl, or http://.https://…/api/v1/ with the trailing slash.
Signed out right after signing inServer clock drift, or a different Firebase project.Sync the server clock; use one Firebase project for app and server.
Google sign-in fails on AndroidMissing SHA-1/SHA-256 in Firebase.Add debug and release fingerprints, re-download google-services.json.
Update required for everyoneMinimum version set too high.Lower it in Settings › App & support › App versions.
Maintenance screen won't go awayMaintenance mode is on.Turn it off in Settings › App & support.
Release build won't signNo android/key.properties.Create the keystore and the file (Release build).
